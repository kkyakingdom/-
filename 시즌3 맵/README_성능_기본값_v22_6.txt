v22.6 · 정철 계산기 성능 및 기본값 개선
- 기준: Scenario11 웹지도 정철 계산 통합 v22.5.
- 정철 입력 중 240ms debounce, 지도 렌더러와 계산기 렌더링 분리. 지도 번호 표시 갱신은 공략 목록의 추가/삭제/순서 변경 또는 패널 표시 전환 시에만 요청.
- 72시간 예상표 및 상세 계산 결과는 해당 섹션을 펼칠 때에만 계산/생성. 공략 목록도 접힌 동안 DOM을 만들지 않음.
- 계산기 패널은 내용 높이에 맞게 축소, 펼치면 최대 화면 높이에서 내부 스크롤.
- 새 입력 또는 초기화 때 시간당 정철 생산량 기본값 160. v22.5에 저장된 이전 기본 생산량 100은 최초 실행 시 160으로 1회 변경. 기타 저장값과 v22.6에서 직접 입력한 100은 유지.
- 경로 출발 시간은 페이지를 열 때 현재 기기 로컬 시간(HH:MM), 사용자가 시간을 지정하기 전에는 경로 탐색 버튼으로 새 탐색을 시작할 때도 현재 시간으로 설정. 사용자가 직접 지정한 시간은 유지.
- 지도 리소스, 원본 연결 데이터, 경로 계산과 정철 계산 규칙 자체는 변경하지 않음.
