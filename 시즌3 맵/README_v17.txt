S3 지도 v17 - 실제 이동 가능 최단 경로

- 상단 경로 탐색 버튼 또는 R 키로 경로 모드 시작
- 첫 클릭: 시작 타일, 두 번째 클릭: 목적지 타일
- 엇갈린 6방향 타일 인접 규칙 적용
- 원본 지형 raw 2(강), raw 3(산)는 이동 불가
- 일반 토지/자원/성지·성채 부지/선교/산길/관문 등 그 외 원본 타일은 이동 가능
- A* 최단 경로, 긴 경로는 비동기 청크 처리로 UI 멈춤 완화
- 경로 타일 수와 실제 이동 횟수(타일 수-1)를 함께 표시

주의: 게임 내부에서 특정 시설 통행에 별도 점령/소속/시즌 규칙이 적용되는 경우, 이 지도는 지형상 통행 가능 여부만 계산합니다.
