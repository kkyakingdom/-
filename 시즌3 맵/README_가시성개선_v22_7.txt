v22.7 가시성 개선 (v22.6 기반)
- 선택 지역: 어두운 외곽 + 흰색 실선의 대비 강화 (주 경계의 청회백색 파선과 구별).
- 클릭하지 않은 성지 연결망: 회청색 단일 색상, 연결 종류의 실선/파선 구분 유지.
- 선택된 성지/관문: 전체 시설명 그리기 후 최상단에 15px 굵은 흰 글씨와 어두운 배경 및 흰색 테두리 배지 표시. 연결망 OFF 상태에서도 선택한 이름 강조.
- 정철 계산기: 현재 보유 정철 / 다음 공략 시설 / 건설 가능 시각을 상단 3분할 요약으로 제공. 기존 계산·저장·지연 갱신 변경 없음.
- 지도 이미지, 지형/좌표, 원본 448건, 이동 경로/출발 시각 규칙 변경 없음.
