Root cause of missing state-border segments in v7.4:
- Tile rendering uses a staggered grid.
- Odd 0-based X columns (= even in-game X) are shifted downward by +0.5 tile.
- The old boundary builder still treated the map as a regular square grid and compared a left/right edge only against the same-Y neighboring tile.
- In the actual staggered grid, one vertical tile edge is shared by two neighboring tiles, one on each half of the edge.
- Therefore v7.4 could omit or misplace half-edge border segments.

v7.5 boundary rule:
- Horizontal top/bottom: compare with same-column y-1 / y+1.
- Vertical left/right edges are split into two 0.5-tile segments.
- For even 0-based X: upper half neighbor = y-1, lower half neighbor = y.
- For odd 0-based X: upper half neighbor = y, lower half neighbor = y+1.
- The same odd/even offset rule is now used by tile rendering, selection outlines, commandery borders, holy-site borders, and state borders.

Hierarchy rendering:
- State boundary: blue solid line.
- Commandery boundary inside same state: orange solid line.
- Holy-site boundary inside same commandery: pale-gold dashed line.
- Boundary classes are exclusive; a state boundary is not simultaneously rendered as commandery/holy-site boundary.
