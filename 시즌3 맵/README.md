# 시즌3 웹지도 v16 · 사용자 화면 정리 / 성능 개선

압축을 해제한 뒤 `index.html`을 실행하면 됩니다. 인터넷 연결 없이 동작하는 웹지도입니다.

## 조작
- 상단 성지·지역 검색 또는 왼쪽 좌표 이동을 이용합니다. 마우스 휠 확대/축소, 드래그 이동, 클릭 선택 기능은 이전과 같습니다.
- 왼쪽 지도 정보창에 마우스 오버 타일 정보와 클릭한 좌표·지역/시설 정보가 함께 표시됩니다. 토지 카운터는 아래 ‘토지 카운터 · 도구’를 눌러 설정할 수 있습니다.
- 오른쪽 자원 필터: 목재·철광·석재·식량과 1~8 / 9 / 10~12레벨을 개별로 표시하거나 숨깁니다. ‘색상 바꾸기’에서 색상 버튼을 누르면 표시 중인 1~12레벨 전체 자원에 같은 색상을 적용합니다. ‘레벨별 기본색 복원’을 누르면 원래대로 돌아갑니다.
- 주(州) 색상 범례와 경계선 안내는 접이식 도움말로 옮겼습니다. `/` 검색, `F` 전체 보기, `P` 정보 접기/펼치기, `Esc` 선택 해제 단축키를 이용할 수 있습니다.

## 최적화
- 자원 표시 재계산 작업을 프레임별로 나눠 UI 입력을 막지 않도록 했으며 새 설정을 고르면 이전 계산을 취소합니다.
- 드래그/확대 미리보기는 계속 보여주고 조작이 끝나면 세부 정보를 선명하게 다시 그립니다.
- 기존 지도 데이터, 경계/성지 위치, 토지 카운터와 좌표 복사 기능 및 로컬 설정은 유지합니다.


v16.1 변경: 좌측 좌표 이동(126px)·지도 정보(238px)·토지 카운터(148px) 패널의 표시 높이와 폭을 고정했습니다. 마우스 호버, 선택 대상, 사용법/도구 펼침에 따라 패널 전체의 크기가 바뀌지 않으며 내용이 길면 해당 패널 안에서 스크롤됩니다. 화면이 낮으면 좌측 패널 전체에도 스크롤이 생깁니다. 자원/좌표 데이터와 지도 렌더링 코드는 변경하지 않았습니다.
