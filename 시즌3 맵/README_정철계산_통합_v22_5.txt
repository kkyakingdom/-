Scenario11 웹지도 v22.5 — 정철 도달 시각 계산기 통합

기준: 성지 연결선 가시성 + 24시간제 경로 출발시각 + 경계·경로·선택 영역 가시성 조정 v22.4

[실행]
압축을 푼 뒤 Scenario11_웹지도_v22 폴더의 index.html을 실행하세요.
외부 EXE, 설치, 인터넷 연결 없이 웹지도 내부에서 정철 계산기를 사용할 수 있습니다.

[사용 방법]
1) 상단 '격문 점령' 우측의 '정철 계산' 버튼 클릭.
2) '지도 선택 ON' 상태에서 성지 또는 관문의 실제 아이콘을 순서대로 클릭.
   시설 이름과 레벨이 원본 Scenario11 지도 데이터에서 자동으로 입력됩니다.
   일반 토지나 아이콘이 아닌 곳을 클릭하면 등록되지 않습니다.
3) '보유 정철', '시간당 생산량', '기준 시각', '생산 반영 텀' 입력.
4) 항목별 '타 진영 +50%', '점령 후 추가 생산/시간', '실제 공성 시각'을 설정할 수 있습니다.
5) 공략 순서 ↑ ↓, 항목 삭제, 72시간 시간별 정철 예상표를 이용할 수 있습니다.
   입력과 공략 순서는 현재 지도의 브라우저 로컬 저장소에 보관됩니다.
6) 좁은 스마트폰 화면에서는 계산기를 열면 지도 선택용 작은 바만 표시합니다.
   시설을 클릭해 추가하고 '계산 목록 보기'를 눌러 입력·결과를 확인합니다.
   다시 '지도 선택 ON'을 눌러 추가 선택으로 복귀할 수 있습니다.
7) 기존 '경로 탐색'이 켜져 있어도 '지도 선택 ON'을 우선 처리합니다.
   계산기를 닫으면 기존 경로 탐색 상태로 되돌아갑니다.

[원본 계산기에서 반영한 계산 규칙]
기본 소모: Lv4=500, Lv6=750, Lv8/9=1000, Lv10/11=1500,
Lv13=2000, Lv14/15=2500, Lv16=3000, Lv18=4500, Lv20=6000.
타 진영: 기본 소모의 1.5배.
건설 시각: 정철이 모인 시각을 다음 15분 단위로 올림.
점령 후 추가 생산: 기본값은 건설 가능 시각 + 3.5시간.
실제 공성 시각을 입력하면 해당 시각 + 1시간 30분부터 추가 생산 반영.
실제 공성 시각이 건설 가능 시각보다 과거로 입력돼 생산 반영이 소급되는 경우,
이 웹지도에서는 계산된 건설 가능 시각 이전으로 생산량 증가를 당기지 않습니다.
경과 예상은 입력한 생산량이 일정하다는 가정의 추정치입니다.

[주요 제한 및 보존 사항]
성지/관문 이외의 시설(부두·성채·산길 등)은 계산 목록에 추가되지 않습니다.
동일한 성지/관문 중복 등록은 방지합니다.
이전에 별도 EXE 계산기에서 저장한 브라우저 데이터는 웹지도로 자동 이전되지 않습니다.
게임사 원본 이미지/시설 마커는 교체하지 않았고, 지도·자원·경계·연결 448건은 수정하지 않았습니다.
이 파일은 사용자가 제공한 기존 프로그램의 공개 UI에 포함된 소모·시간 규칙을
기반으로 만든 별도의 오프라인 웹지도 기능으로 EXE를 내장하거나 실행하지 않습니다.
