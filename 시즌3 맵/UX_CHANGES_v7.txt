S3 업주산하 지도 v7 사용자 기능 개선 검증

1. 좌표 검색
- 기존 X / Y 두 입력칸 제거
- 단일 입력 형식 X.Y 지원 (예: 837.333)
- 편의를 위해 X,Y / (X,Y) 형식도 허용
- 허용 범위: X 1~1500 / Y 1~1500
- Enter 키와 이동 버튼 모두 동작

2. 좌표 검색 이동
- 검색 즉시 최대 확대 배율 30으로 이동
- 검색 타일이 화면 중앙에 오도록 staggered-column 보정을 포함해 중앙 정렬
- 검색한 타일은 금색 반투명 채움 + 이중 테두리 + 중앙점으로 고정 강조
- 단순 마우스 hover로 강조가 사라지지 않음
- 다른 지도 선택/지역 검색/전체 보기 시 검색 타일 강조를 해제

3. UI 정리
제거:
- '관문 34개·부두 67개는 S3 원본 center_pos 좌표 적용'
- 원본 타일 로딩/좌표보정/공터·강·산 수량 표시
- raw 0 / raw 2 / raw 3 / 특수지형 범례
- 성지 선택 정보의 내부 '유형' 번호
- 구조물 선택 정보의 '구조물' 분류 행
- 구조물 선택 정보의 '원본 ID'
변경:
- '원본 타일 정보' -> '타일 정보'

4. 기존 정확도 보정 유지
- 인게임 짝수 X열 +0.5칸 stagger 규칙 유지
- terrain/resource (+1,+1) 원본 layer 좌표 보정 유지
- v6 자체검증/타일 데이터 판정 로직 유지

정적 검증
- app.js: node --check 통과
- 단일 좌표 입력 ID 존재 / 구 X,Y 입력 ID 제거 확인
- 최대 확대 이동 코드 확인
- 검색 타일 독립 강조 렌더러 확인
- 요청된 내부 UI 문자열 제거 확인
