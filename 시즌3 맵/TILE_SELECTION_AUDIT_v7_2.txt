타일 선택 정보 분리 v7.2

[문제]
고배율 타일 클릭 시 다음 정보가 동시에 표시됨:
- 클릭 타일
- 소속 지역
- 해당 지역 성지
- 클릭 지점 근처 구조물(nearestStructure 반경 검색)

[수정]
1. 고배율(scale > 6) 타일 클릭
   - 클릭 좌표를 정수 타일(tx,ty)로 확정
   - structureAtTile(tx,ty)로 정확히 동일 타일의 구조물만 조회
   - updateInfo(null, selectedTile, exactStructure) 호출
   - 지역/성지 정보는 표시하지 않음

2. 좌표 검색
   - 검색한 타일 하나만 표시
   - 구조물도 동일 타일일 때만 표시

3. 저배율 지역 선택
   - 기존 지역/성지 정보 표시 유지

[검증]
- JavaScript 문법 검사(node --check) 통과
- 고배율 selectedTile 호출부 2곳 모두 regionCode 미전달 확인
- nearestStructure는 저배율 지역/구조물 탐색에만 유지
